Before you write

These quick checks solve most connection problems:

  • Use the latest version of Paper Maze.
  • Check that your internet connection is stable.
  • Close and reopen the game, then try again.
  • Ask the host for a fresh room code.

Quick fixes

Try these first.

Paper Maze matches happen live, so a room code and a steady connection matter most.

1

Can’t join a room?

Re-enter the code exactly as shown. If the match has already started or the room has closed, ask the host to create a new room.

2

Connection interrupted?

Keep the game open while it reconnects. If it does not return to the match, restart the app and check your network connection.

3

Something looks wrong?

Restart the game first. If the issue remains, send us your device model, OS version, app version, and a screenshot if possible.

Frequently asked questions

A few useful answers.

What should I include in a bug report?

Tell us what you expected, what happened instead, and the steps that led to the problem. Include your device model, operating system version, Paper Maze version, approximate time of the issue, and a screenshot or screen recording when possible.

Do I need an email account to play?

No. Paper Maze uses a device-based player profile, so you do not need to register with an email address or password to start playing.

How do I delete my player account and data?

Open Paper Maze, go to Settings → Account, and tap Delete player account. This permanently deletes the guest account and its associated game data. If you no longer have the app, use our account deletion page to submit a request.

Where can I read the privacy policy?

The complete Paper Maze Privacy Policy explains what information the game uses, why it is needed, and how to contact us about privacy.

Still need a hand?

Send us a clear description of the problem. Please do not include passwords, payment details, or other sensitive information.
